# Contributing to Markbit

Bug reports, ideas, and pull requests are welcome.

## Contributor License Agreement

Markbit is dual-licensed: it is available under an open source license (see
[LICENSE](LICENSE)) and under commercial licenses. So that contributions can be
shipped under both, every contributor needs to sign the
[Contributor License Agreement](CLA.md) once before their first pull request
can be merged. You keep the copyright in your work.

Signing is done on the pull request itself:

1. Open your pull request.
2. The CLA bot comments with a link to [CLA.md](CLA.md).
3. If you agree, reply on the pull request with exactly:

   ```
   I have read the CLA Document and I hereby sign the CLA
   ```

The bot records your signature, and future pull requests from you pass the
check automatically. If the check doesn't update, comment `recheck`.

## Development

See the [Development](README.md#development) section of the README for setup,
build, and test commands. Please run `npm run type-check` and the relevant tests
before opening a pull request.
